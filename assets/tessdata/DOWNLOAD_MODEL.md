# Tesseract LSTM Model

Download the English LSTM model before building with the `offline-ocr` feature:

```bash
curl -L "https://github.com/tesseract-ocr/tessdata_best/raw/main/eng.traineddata" \
  -o eng.traineddata
```

File size: ~10 MB  
This file is excluded from version control (see .gitignore).
